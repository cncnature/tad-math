# TAD 수학 만지기 × STUDYGOD(로컬 LLM) × 일평제국 — 통합 업그레이드 로드맵

작성 2026-10-31. 세 시스템의 역할을 나누고, 학습 데이터·보상·AI 를 한 줄로 잇는 계획.

| 시스템 | 성격 | 강점 | 약점 |
|---|---|---|---|
| **TAD 수학 만지기** (GitHub Pages, 정적) | 공개 웹, 로그인 선택(Firebase) | 어디서나 접속, 89 소단원·175 공식·생성기·논술·패턴·유도 공방 | 서버 없음 → LLM 불가, 채점은 객관식/자기채점 |
| **STUDYGOD** (Flask + SQLite + Ollama, 로컬) | 집 PC 전용 | 4과목, FSRS 복습, 시험지 사진 분석, **LLM 튜터·문항 생성**, 골드 차등 지급 | 설치 필요, 외부 접속 불편, 수학 문항 144개 |
| **일평제국** (정적 게임) | 보상 | 몰입도 | 학습과 분리돼 있었음 → 이번에 학습 시간 게이트로 연결 |

## 0. 이번에 구현한 것 (2026-10-31)
- **게임 시간 지갑** (`#/tokens`): 첫 정답 +2분, 생성 문제 +1분(일 15분), 목표율 100% +10분, 유도 공방 +3/+8, 복습 +1, 진단 +5, 하루 코스 +10, 주간 테스트 정답당 +1(1등급 +5), 클리닉 졸업 +5, 일 상한 120분. STUDYGOD 골드 정책(반복 감액)과 같은 원칙 — **첫 정답만 인정**.
- **전송 코드**: `{m,t,n,s}` base64url, `s = FNV-1a(m|t|n|secret)`, 7일 만료, nonce 1회용. 일평제국은 `#study=코드` 로 열리면 자동 충전, 게임 내 ⏱ 칩에서 수동 붙여넣기도 가능. 매일 무료 10분, 보호자 PIN(기본 2026) 30분 충전.
- **주간 테스트** (`#/weekly`): 학원식 정기 평가 — 약한 소단원 우선 10문항, 15분, 추정 등급, 틀린 소단원 자동 클리닉 등록.
- **오답 클리닉** (`#/clinic`): 같은 유형 생성 문제 3개 전부 정답 × 3회(당일·3일·7일) 졸업제.

## 1. STUDYGOD ↔ GitHub(TAD) 연동 — 3단계

### 1단계 (1주) — 기록 교환, 코드 변경 최소
- TAD 의 `#/notes` "기록 내보내기" JSON 에 `qlog, tok, forge, weekly, clinic, me` 포함(현재 quiz·diag·srs·essay·daily 만 → 확장).
- STUDYGOD 에 `/api/import/tad` (POST JSON) 추가: `qlog` → `studentanswer`(question_id 는 `tad:lesson:idx` 가상 id), `srs` → `reviewcard`(FSRS 초기화), `diag.broken` → `weakprofile`. 역방향 `/api/export/tad` 로 STUDYGOD 의 복습 due·약점 개념을 TAD 가 읽을 수 있는 JSON 생성.
- 효과: STUDYGOD 의 **시험 분석·학습 가이드·AI 튜터**가 TAD 에서 쌓인 수학 기록을 보고 코칭.

### 2단계 (2~3주) — 로컬 AI 튜터를 TAD 안에 끼워 넣기
- STUDYGOD `app.py` 에 CORS(`flask-cors`, origin `https://cncnature.github.io`) 를 켜고 `/api/chat`, `/api/generate`, `/api/faded/<id>`, `/api/coaching` 을 그대로 노출.
- TAD `js/app.js` 에 `window.LOCAL_AI` 탐지: 페이지 로드 시 `http://localhost:5100/api/dashboard` 를 1초 타임아웃으로 ping → 성공하면 소단원 페이지에 **"🤖 AI 튜터에게 묻기"** 패널, 틀린 문제 옆 **"왜 틀렸는지 설명"**, 대시보드 컨설팅에 LLM 코칭 문단 추가. 실패하면 조용히 숨김(공개 사이트는 그대로 동작).
- 프롬프트는 TAD 데이터(소단원 concept·why·pitfalls·사용자 정답률)를 컨텍스트로 넘겨 **교과 범위 안에서만** 답하게 함. 모델은 현재 `exaone3.5:2.4b` → 수학 설명력은 `qwen3:8b`/`gemma3:12b` 권장(12GB VRAM 기준).
- 같은 와이파이의 태블릿에서는 `http://[PC IP]:5100` 을 설정에 입력하도록 `#/setup` 에 "로컬 AI 주소" 칸.

### 3단계 (한 달) — LLM 으로 콘텐츠 자동 생산 → GitHub 로 커밋
- STUDYGOD `/api/generate` 를 확장해 TAD 의 `data/*.js` 스키마(quiz `{q,opts,a,exp,tag}`, 서술형 `{q,model,rubric,pitfalls}`, 유도 `{steps[{t,why,alt,blank}],traps}`)로 바로 출력.
- 검증 파이프라인: ① 생성 → ② `scripts/check.js` 로 구조 검증 → ③ **답 검산기**(생성기 `js/gen.js` 의 역연산, 또는 sympy) → ④ 사람이 승인(STUDYGOD 화면에서 ✓) → ⑤ `gh api` 로 `data/generated-YYYYMM.js` 커밋·푸시 → Pages 자동 배포.
- 이렇게 하면 "매주 새 동형 문제 50개" 가 사람 손 없이 사이트에 쌓이고, 저작권 문제 없는 자체 문항 은행이 됨.

### 공통 데이터 계약 (JSON)
```json
{"v":1,"user":"tad","events":[{"k":"lesson:quadratic-eq","i":"2","ok":1,"t":1793400000000}],
 "mastery":{"quadratic-eq":{"pct":80,"acc":0.88}},"srs":{"quadratic-formula":{"n":2,"due":1793500000000}},
 "clinic":{"factoring":{"done":1,"next":1793650000000}},"tok":{"bal":15}}
```
Firebase 를 쓰는 사용자는 TAD 가 이미 `users/<uid>/data` 에 같은 키를 올리므로 STUDYGOD 가 Firebase Admin 으로 읽어도 됨(2단계 대안).

## 2. 대치동·시대인재식 시스템을 TAD 에 반영하기

학원 플랫폼이 실제로 하는 일을 기능으로 번역했다. 기출 문항 원문은 저작권이 있어 넣지 않고, **구조·운영 방식**을 가져온다.

| 학원 시스템 | 핵심 | TAD 반영 (완료 ✓ / 계획 ○) |
|---|---|---|
| 레벨 테스트 → 반 배정 | 입학 시 수준 진단, 분기마다 재배정 | ✓ 진단(끊긴 고리) · ○ 분기별 **재진단 알림**과 '반' 명칭(기초/개념/심화/최상위) 부여 |
| 주간 테스트 (W-test) | 매주 진도 범위 10~20문항, 컷·등수 | ✓ `#/weekly` 10문항 15분 추정 등급 · ○ 로그인 사용자 간 **익명 백분위**(Firebase classes 집계) |
| 오답 클리닉 | 틀린 문제 유형 재시험, 통과까지 반복 | ✓ `#/clinic` 3회 졸업제 |
| 서바이벌 모의고사(시대인재) | 수능 전 범위 100분 실전, 상위권 변별 | ○ `#/survival`: 수능 패턴 31 + 학교 시험 116 + 생성 문제로 **30문항 100분 시험지 모드**(`#/paper` 재사용), 등급컷 추정, 오답 유형 리포트 |
| 데일리 테스트/숙제 검사 | 매일 소량, 미제출 추적 | ✓ 하루 10분 코스 · 주간 계획 · ○ 미완료 시 보호자 알림(이메일/카카오 — Firebase Functions) |
| 유형서(쎈·블랙라벨 식 유형 분류) | 유형 번호별 반복 | ✓ 수능 패턴 도감(신호·첫 수) · ○ 소단원별 **유형 코드**(예: Q8-03 "근과 계수 역산") 를 모든 문항에 붙이고 유형별 정답률 히트맵 |
| 첨삭·서술형 클리닉 | 풀이 과정 채점 | ✓ 논술·서술형 루브릭 자기채점 · ○ 2단계 로컬 LLM 첨삭 |
| 학부모 리포트 | 주간 출석·점수·코멘트 | ○ `#/report` 주간 PDF(인쇄) — 목표율 변화, 주간 테스트, 클리닉 졸업, 게임 시간 사용량 |
| 선행 로드맵 | 학년 상관없이 개념 선후로 진도 | ✓ 개념 지도·줄기로 보기 · ○ "선행 트랙": 다음 학기 소단원을 목표율 70% 이상인 선수 개념만 열리게 잠금 |

**우선순위 제안**: ① 서바이벌 모의고사(기존 자산 재조합이라 2~3일) → ② 유형 코드·히트맵 → ③ 학부모 주간 리포트 → ④ 익명 백분위(로그인 사용자 수가 쌓인 뒤).

**하지 말아야 할 것**: 시대인재·대치 학원 실제 시험지 스캔 업로드로 문항을 복제하는 것(저작권·계약 위반). STUDYGOD 의 시험지 사진 분석은 **본인이 치른 학교 시험의 약점 분석**에만 쓰고, 문항 은행은 LLM + 생성기 + 검산 파이프라인으로 자체 생산한다.
