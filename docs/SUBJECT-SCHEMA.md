# 과목 데이터 스키마 (국어·영어·과학·사회·역사) — `data/subjects/<id>.js`

수학(`data/curriculum.js`)과 같은 목표: **2022 개정 교육과정 성취기준 → 핵심 개념 → 오개념·함정 → 출제 포인트 → 풀이 패턴 → 확인 퀴즈 3**. 내신(중간·기말)과 학력평가·수능 공통 출제 방향을 함께 적는다. 교과서(출판사)마다 단원 순서가 다르므로 **성취기준 코드 단위**로 쓰고, 단원 제목은 가장 흔한 교과서 표기를 쓴다.

```js
window.DATA = window.DATA || {}; window.DATA.subjects = window.DATA.subjects || {};
window.DATA.subjects.sci = {
 id:"sci", name:"과학", icon:"🔬", grade:"g22", term:2,          // grade: g22(중2) 등, term: 1|2 (현재 학기)
 src:[["교육부 고시 제2022-33호 [별책 9] 과학과 교육과정","https://..."]],  // 근거 문서 (필수, 실제 연 URL)
 units:[
  { id:"sci-matter", title:"물질의 구성", std:["9과02-01","9과02-02"],   // std: 성취기준 코드
    exam:"중간·기말 모두. 원소 기호·이온식 쓰기 서술형이 단골",            // 이 단원의 내신 출제 경향 한 줄
    lessons:[
     { id:"sci-atom", title:"원소·원자·분자", std:["9과02-01"],
       concept:["**원소**: 더 이상 분해되지 않는 물질의 기본 성분(산소·수소 …).", "…(3~5개, **굵게** 가능, 수식은 $...$)"],
       why:"왜 이렇게 구분하는지 한 문단(학생 말투 아님, 설명문).",
       pitfalls:["원소와 원자를 같은 말로 씀 — 원소는 '종류', 원자는 '알갱이'", "…(2~3개)"],
       points:["원소 기호 20개 쓰기(서술형)", "분자 모형 그림 보고 분자식 쓰기", "…(3개, 내신·학평 출제 포인트)"],
       pattern:["'그림(모형) → 분자식' 문제: 같은 색 공의 개수를 세어 원자 수 → 아래 첨자", "…(1~2개, 문제 풀이 방식·접근 순서)"],
       memo:"꼭 외울 한 줄 (예: H₂O 는 수소 2 + 산소 1 = 물 분자 1개)",
       quiz:[ {q:"다음 중 원소가 아닌 것은?",opts:["산소","수소","물","철"],a:2,exp:"물은 수소와 산소로 분해되는 화합물."}, {…}, {…} ]   // 3문항, 4지선다, a 는 0~3
     }
    ]}
 ]
};
```

규칙
- **학년 확장 파일**: 학년별 추가 단원은 별도 파일 `data/subjects/<과목>-g3.js`(중3), `-h1.js`(고1), `-h2.js`(고2), `-h3.js`(고3) 에 다음 형식으로 둔다(기본 파일은 건드리지 않는다). 사이트·check.js·브리핑이 자동으로 합친다.
  ```js
  window.DATA = window.DATA || {}; window.DATA.subjectsExtra = window.DATA.subjectsExtra || [];
  window.DATA.subjectsExtra.push({ sid:"soc", grade:"h1", src:[["교육부 고시 … 별책 7","https://…"]], units:[ { id:"soc-h1-human-rights", title:"통합사회1 · 인권 보장과 헌법", std:["10통사1-03-01"], exam:"…", lessons:[ … ] } ] });
  ```
  학년 코드: 중3 1학기 `g31`, 2학기 `g32`(단원마다 `grade` 로 구분 가능), 고1 `h1`, 고2 `h2`, 고3 `h3`.
- **학년 확장**: 단원에 `grade:"g31"|"h1"|…` 를 붙이면 그 학년 단원으로 취급한다(없으면 과목의 기본 `grade`). 한 과목 파일에 중2~고3 단원을 함께 넣어도 되고, 매일 브리핑은 학생 학년의 단원만 고른다. 과목이 학년에 따라 이름이 바뀌는 경우(통합사회·통합과학·공통국어 등)는 단원 제목에 과목명을 쓰고 파일은 같은 과목(soc·sci·kor)에 둔다.
- 모든 `id` 는 과목 접두어(`kor-`, `eng-`, `sci-`, `soc-`, `his-`)로 시작하고 사이트 전체에서 유일.
- `quiz` 는 정확히 4지선다, 정답 하나, `exp` 필수. 교과서·문제집 원문을 베끼지 않고 새로 쓴다(저작권). 지문이 필요한 국어·영어는 **짧은 자작 지문**(3~5문장)을 `q` 안에 넣는다.
- 역사: `his.js` 하나에 `track:"world"|"korea"` 를 단원에 붙인다(중2 역사①은 세계사 중심, 역사②는 한국사).
- 영어: 문법·독해 전략·어휘 — 성취기준은 기능 중심이므로 `std` 에 `[9영02-05]` 형식으로 가장 가까운 코드를 쓰고, 단원은 '2학기 공통 문법'(관계대명사·수동태·현재완료·접속사·to부정사/동명사·비교)으로 구성.
- 국어: 문학(시·소설 개념어), 읽기(설명·논증 구조), 문법(품사·문장 성분·음운), 쓰기·화법·매체 — 성취기준 코드 `[9국05-02]` 형식.
- 수학 `std` 도 같은 방식으로 `[9수02-12]` 를 각 소단원에 붙인다(별책 8 기준).
- 검증: `node scripts/check.js` 가 id 유일성·quiz 형식·std 형식을 검사한다.
